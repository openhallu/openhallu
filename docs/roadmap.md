# OpenHallu Roadmap

## Phase 0 — Foundation

Goal:
- define product scope
- define module ownership
- define MVP

Deliverables:
- product brief
- site architecture
- mitigation module plan
- collaboration workflow

## Phase 1 — Content and Data Design

Goal:
- define the content schema before UI implementation

Deliverables:
- paper schema
- toolbox schema
- benchmark schema
- detection schema
- initial mitigation taxonomy

## Phase 2 — Frontend Shell

Goal:
- build the public-facing site skeleton

Deliverables:
- homepage
- top-level nav
- module landing pages
- initial visual system

## Phase 3 — Mitigation MVP

Goal:
- ship the strongest first module

Deliverables:
- mitigation landing page
- mitigation paper cards/list
- toolbox section
- GitHub repo outbound links

## Phase 4 — Paper Ingestion

Goal:
- populate the mitigation module with real content

Deliverables:
- curated mitigation paper set
- normalized metadata
- tags and categories
- linked repos/toolboxes where available

## Phase 5 — Benchmark and Detection Expansion

Goal:
- expand the rest of the site around the initial content model

Deliverables:
- benchmark page
- detection page
- shared papers index

## Phase 6 — Collaboration and Automation

Goal:
- make the project easier to maintain with collaborators

Deliverables:
- contribution workflow
- shared review rules
- optional automated ingestion helpers

## Immediate Execution Order

1. finalize plan and data schema
2. choose frontend stack
3. scaffold site
4. implement homepage + mitigation page
5. ingest mitigation papers
6. attach toolbox repos
